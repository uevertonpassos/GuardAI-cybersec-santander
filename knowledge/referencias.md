# Referências para estudar e fundamentar decisões

Consultadas em 17/11/2026. Os exemplos e a matriz de risco deste projeto são próprios; não representam uma certificação destas organizações.

- [MITRE CWE-89](https://cwe.mitre.org/data/definitions/89.html): classificação da injeção SQL.
- [OWASP — SQL Injection Prevention](https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html): uso de consultas parametrizadas e separação entre instrução e dados.
- [Python — sqlite3](https://docs.python.org/3/library/sqlite3.html): API utilizada pelo laboratório e parâmetros de consultas.
- [OpenAI — Build skills](https://learn.chatgpt.com/docs/build-skills): estrutura de skills e descoberta no repositório.
- [GitHub — checkout](https://github.com/actions/checkout) e [setup-python](https://github.com/actions/setup-python): ações usadas no workflow.

Use fontes primárias para aprofundamento. Não transforme a leitura de uma referência em evidência de que uma ferramenta foi executada.
